# Linux context

I do much of my development on a Linux PC with an Arch-based distribution. This
is currently a personal development environment. More Linux environments may be added later,
including an environment used for professional work.

Detect the actual host and project environment. Don't assume every Linux machine
has the same repositories, accounts, credentials, packages, or access. Apply the
shared personal/work boundaries wherever they are relevant.

Use the project's existing toolchain and the configured Linux environment. Keep
machine-specific configuration separate from portable instructions. iOS simulator
and Xcode work belongs on a configured Mac; don't assume a remote Mac is available.
